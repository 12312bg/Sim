# Sim 设计与开发路线

参考类型：Plague Inc.（瘟疫公司）、Religion Inc. God Simulator。核心循环：

> 选起点 → 在地区内增长、沿连接扩散 → 点击气泡获得点数 → 购买升级改变传播属性 → 与对抗力量赛跑 → 获胜 / 失败 / 到期评级

游戏分为多个**主题**（类似瘟疫公司里病毒、细菌等不同病原体类型）。每个主题是一份数据文件，
自带能力树、事件、规则、时间轴和文案；模拟代码不随主题变化。

## 目录

```
scripts/sim/        纯模拟层（无场景树依赖，可无界面测试）
  sim_world.gd        状态 + 回合推进 + 气泡/事件 + 胜负 + 存档序列化
  region.gd           地区状态（未转化 / 信徒（含狂信徒）/ 流失者 / 移除、警觉、封锁）
  spread_model.gd     传播、狂热、世俗化、回流等公式（纯函数）
  upgrade_tree.gd     能力树：前置、年代门槛、花费、属性加成汇总
  opposition.gd       反制进度条（原型主题使用）
scripts/core/
  game.gd             自动加载单例 Game：主题开局、时钟倍速、气泡寿命、存读档
  data_loader.gd      JSON 读取、规则深度合并、主题列表
scripts/map/          世界地图渲染与相机
scripts/ui/
  main.gd             主界面（代码搭建）
  bubble_layer.gd     可点击的气泡
data/themes/          主题（index.json 登记；religion.json 可玩，prototype.json 仅测试）
data/scenarios/       场景：地区、连接、基础规则
data/map/             地图元数据与边界线
assets/fonts/         内嵌中文字体 Noto Sans SC（SIL OFL 1.1，许可见同目录）
tools/map_pipeline/   地图与场景生成管线
tests/run_tests.gd    无界面测试 + 平衡报告
```

## 主题系统

主题文件（`data/themes/<id>.json`）字段：

| 字段 | 说明 |
|---|---|
| `scenario` | 使用的场景（地区划分与连接） |
| `time` | `unit`（`day`/`year`）、起止年份、各档倍速的“秒/回合” |
| `population_curve` | 可选：世界人口随年代变化（各地区按现代人口等比缩放） |
| `labels` | 文案：信徒、狂信徒、点数名称、新闻模板（`{agent}`、`{region}` 占位） |
| `map_colors` | 地图三色：`converted` / `zealot` / `lapsed` |
| `categories` | 能力树（分页）名称 |
| `rules` | 覆盖场景规则（深度合并） |
| `upgrades` | 升级：`cost`、`requires`、`min_year`（年代门槛）、`effects` |
| `events` | 事件：权重、年代范围、范围（地区/全球）、持续时间、效果、即时效果、新闻 |

新增主题 = 新建一个 JSON 并登记到 `data/themes/index.json`。`hidden: true` 的主题不出现在新游戏对话框里。

## 宗教主题（第一个主题）

- **时间**：公元前 1000 年起，每回合一年，到 2100 年结束。世界人口按历史估计曲线变化（约 5000 万 → 2019 年 77 亿 → 2100 年 104 亿）。
- **地区**：45 个文化地区（大国单列，其余按文化圈合并），划分见 `tools/map_pipeline/region_groups.json`。
- **人群**：未皈依者、信徒、狂信徒（信徒的一部分）、无神论者。
- **狂热**：信徒以 `zeal` 的速率变为狂信徒，狂信徒以 `zeal_decay` 的速率冷却回普通信徒，
  所以狂信徒比例会趋向 `zeal / (zeal + zeal_decay)`，需要持续投入教义来维持。
  狂信徒还能通过 `zealot_spread` 加强传播。
- **世俗化**（代替反制进度条）：1650 年起出现，速率每 70 年翻倍（上限 3%/年）。
  - 普通信徒按这个速率变为无神论者；未皈依者也会世俗化，速度减半；**狂信徒不受影响**。
  - 富裕地区的世俗化速度是基准的 1.6 倍，中等地区 1.0 倍，贫困地区 0.5 倍。
  - `secular_resist`（适应树）最多抵消 90%。
- **回流**：`revival`（教义树“宽恕与回归”“复兴运动”等）让无神论者重新皈依，速度与当地信徒比例成正比。
- **能力树**：
  - **传播**：国内传播与陆/海/远途扩散。印刷 1450、广播 1920、网络 1995 有年代门槛。
  - **教义**：狂热、狂信徒传教、信仰点加成、回流。
  - **适应**：气候与富裕度适应、抵御世俗化。
- **事件气泡**：神迹、布道者、朝圣潮、君主皈依、圣典成书、大公会议、大觉醒、公开辩论。点击后触发，部分有年代范围。
- **胜负**：
  - 信徒达到存活人口的 99% 时提前获胜；信徒归零则失败。
  - 到 2100 年未达成，则按信徒占比评级：S ≥ 90%、A ≥ 75%、B ≥ 50%、C ≥ 25%，其余为 D。B 及以上算胜利。
- **起名**：开局给信仰起名，显示在新闻中（如“「光明之道」传入 印度”）。

当前平衡（`tests/run_tests.gd` 的平衡报告，从新月沃地开局，模拟完美收集气泡）：

| 策略 | 结果 |
|---|---|
| 不买升级 | D |
| 只买传播 | 基本 D：没有狂信徒，信徒被世俗化吞掉 |
| 传播 + 适应 | A / B |
| 三棵树均衡 | 大多 S，偶尔提前获胜 |

调参可用：

```bash
godot --headless --path . -s res://tests/run_tests.gd -- religion_balance
```

## 气泡

- 信仰点气泡：每当全球新增皈依人数达到世界人口的 0.5%，就在新增最多的地区冒出一个；首次传入新地区时也会冒出。
  同一地区的点数气泡会合并数值。
- 事件气泡：每回合有一定概率在有信徒的地区出现，点击后触发事件。
- 气泡按**现实时间**计时（默认 8 秒，暂停时不计时），与倍速无关；最后 30% 时间闪烁，过期消失。同时最多 8 个。
- 模拟层只负责产生和结算气泡（`collect_bubble` / `discard_bubble`），过期由 `Game` 按现实时间处理，因此测试可以完全确定性地运行。

## 世界地图

数据全部来自 **Natural Earth**（公共领域，可商用，无需署名）：
- 底图：`GRAY_HR_SR_OB_DR`，灰色晕渲 + 海底地形 + 水系，最高精度 21600×10800（1 像素 = 1/60°），无损 PNG 切成 4×2 块（约 69MB）。
- 边界：`ne_10m_admin_0_countries_chn`，**中国视角**（台湾并入中国版图）。245 个要素，233 个参与模拟。

由 `tools/map_pipeline/build_world_map.py` 一键生成（`--skip-relief` 跳过切底图）：

| 产物 | 说明 |
|---|---|
| `assets/map/relief/*.png` | 底图分块，导入时开启 mipmap |
| `assets/map/region_ids.png` | 国家索引图（半分辨率，像素值 = 国家索引），用于着色和点选 |
| `data/map/world_map.json` | 国家名称、标注点、范围框 + 边界线。每段边界记录两侧国家（海岸线另一侧为空） |
| `data/scenarios/world.json` | 国家级场景（暂无主题使用） |
| `data/scenarios/world_regions.json` | 文化地区场景（宗教主题）：按 `region_groups.json` 合并人口、特征和连接。重新生成时保留其中的 `rules` / `labels` |

数据修正写在脚本顶部：
- 中国人口补入台湾地区人口；“中国香港/中国澳门”命名；黄岩岛并入中国；
- 南极洲和人口不足 1000 的地区不参与模拟；
- “索引图上相邻但隔海”的国家对改为海路；法属圭亚那造成的“法兰西—南美陆路相邻”改为海路。

连接生成：
- 陆路 = 索引图上相邻；
- 海路 = 海岸间距 < 700km 的最近 4 个邻国；
- 空路（宗教主题里显示为“远途”）= GDP 前 25 的国家为枢纽，其余国家连到最近的枢纽。

合并为文化地区时，同一对地区之间同类型的连接取最大权重。**这些都是启发式结果，可以手工调整。**

渲染（`scripts/map/world_map.gd`）：
- 底图分块 → 着色层（索引图 + 调色板着色器，按国家查所属地区的颜色，边缘平滑）；
- 海岸线与地区内国界画 1 像素细线，地区之间的边界画 2 像素粗线；
- 标注显示地区名，放大后再显示国名，带避让。

> 注意：游戏中出现真实世界地图，在中国大陆发行一般需要地图审核（审图号）。中国视角数据可以减少问题，但不能代替审核。

## 通用模拟规则

每回合按顺序：
1. 人口按年代缩放（有人口曲线时），过期事件效果失效；
2. 各地区依次计算：内部传播（logistic）、狂热变化、世俗化、回流、移除、警觉与封锁；
3. 跨地区传播；
4. 反制进度（启用时）；
5. 产生信仰点气泡和事件气泡；
6. 结算胜负。

升级和事件的 `effects` 都是加法属性，键名见 `spread_model.gd` 顶部注释。

所有随机数来自 `SimWorld.rng`（固定种子可复现）。存档用二进制编码（Marshalls/base64），浮点数逐位精确，读档后结果与不中断时完全一致（有测试覆盖）。

## 运行

```bash
godot --headless --path . --import
godot --headless --path . -s res://tests/run_tests.gd
```

在编辑器中按 F5 运行。操作：
- 开局对话框选择主题并起名；
- 点击地图选中地区，再点“在此地区开始”；
- 点击气泡收集；
- 左键拖动、滚轮缩放、WASD 平移；
- Tab 收起或展开右侧面板。

5. 更多事件（含负面事件：宗教分裂、迫害、瘟疫），以及事件选项。
6. 第二个主题。
7. 主菜单、难度、本地化、音效、成就。

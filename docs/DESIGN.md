# Sim 设计与开发路线

参考类型：Plague Inc.（瘟疫公司）、Religion Inc. God Simulator。
两者核心循环相同，只是主题不同：

> 选起点 → “传播体”在地区内增长、沿连接扩散 → 获得点数 → 购买升级改变传播属性 → 与全球反制力量赛跑 → 全覆盖获胜 / 反制完成或消亡失败

所以框架做成**主题无关**：病毒、宗教、品牌、谣言……只需要换 `data/` 里的文案、地区和升级。

## 目录

```
scripts/sim/      纯模拟层（无场景树依赖，可无界面测试）
  sim_world.gd      状态 + 每日推进 + 胜负 + 存档序列化
  region.gd         地区状态（未转化 / 已转化 / 已移除、警觉、封锁）
  spread_model.gd   传播公式（纯函数）
  upgrade_tree.gd   升级树：前置、花费、属性加成汇总
  opposition.gd     反制进度（解药 / 科学）
scripts/core/
  game.gd           自动加载单例 Game：时钟、倍速、存读档
  data_loader.gd    JSON 读取
scripts/ui/main.gd  调试界面（代码搭建）
data/scenarios/     地区、连接、规则系数、文案标签
data/upgrades/      升级定义
tests/run_tests.gd  无界面测试 + 平衡报告
```

## 世界地图

数据全部来自 **Natural Earth**（公共领域，可商用，无需署名）：
- 底图：`GRAY_HR_SR_OB_DR`，灰色晕渲 + 海底地形 + 水系，最高精度 21600×10800（1 像素 = 1/60°），无损 PNG 切成 4×2 块（`assets/map/relief/`，约 69MB）。
- 边界：`ne_10m_admin_0_countries_chn`，**中国视角**（台湾并入中国版图）。245 个要素，233 个参与模拟。

由 `tools/map_pipeline/build_world_map.py` 一键生成（依赖见同目录 `requirements.txt`）：

| 产物 | 说明 |
|---|---|
| `assets/map/relief/*.png` | 底图分块，导入时开启 mipmap |
| `assets/map/region_ids.png` | 地区索引图（半分辨率，像素值 = 地区索引），用于着色和鼠标点选 |
| `data/map/world_map.json` | 地区名称、标注点、范围框 + 简化后的矢量边界线（容差 0.5 像素，肉眼无损） |
| `data/scenarios/world.json` | 模拟场景：人口、气候（按纬度）、富裕度（按收入分组）、陆/海/空连接。重新生成时保留已手调的 `rules` / `labels` |

数据修正写在脚本顶部：中国人口补入台湾地区人口；“中国香港/中国澳门”命名；黄岩岛并入中国；南极洲和人口不足 1000 的地区不参与模拟；
澳大利亚—巴布亚新几内亚等“索引图上相邻但隔海”的地区对改为海路。

连接生成规则：陆路 = 索引图上相邻；海路 = 海岸间距 < 700km 的最近 4 个邻国（偏远岛国连最近的一个）；
空路 = GDP 前 25 为枢纽，枢纽互连最近 6 个，其他人口 ≥ 50 万的国家连最近 2 个枢纽。**这是启发式结果，后续可手工调整主要航线和港口。**

渲染（`scripts/map/world_map.gd`）：底图分块 Sprite2D → 着色层（索引图 + 256 色调色板着色器，对 4 邻像素先查色再双线性混合，边缘平滑）
→ 1 像素矢量边界线 → 带避让的国名标注。相机（`map_camera.gd`）：左键拖动、滚轮缩放（最大 3 倍原始精度）、WASD 平移。

> 注意：
> - 游戏中出现真实世界地图，在中国大陆发行一般需要地图审核（审图号）。中国视角数据可以减少问题，但不能代替审核。
> - 国名标注目前使用系统字体回退显示中文；发布前应内嵌一套中文字体（如 Noto Sans SC，OFL 许可）。

## 模拟规则（当前版本）

每天按顺序：

1. **地区内部传播**（logistic）：`新增 = 已转化 × base_spread × 环境系数 × 未转化/存活`
   环境系数 = `1 + spread − Σ max(特征阻力 − 对应抗性, 0)`，特征如气候、富裕度，阻力表在 `rules.trait_resist`。
2. **移除**：`已转化 × (base_lethality + lethality)`。Religion 式玩法设为 0。
3. **警觉度**：随可见度与转化比例上升；超过 `closure_threshold` 后封锁 `closure_types` 中的连接。
4. **跨地区传播**：每条连接每天一次判定，概率 = `cross_base × 权重 × (1 + cross_<类型>) × 源地区输出强度`，被封锁则 ×(1 − closure_strength)。
5. **反制**：全球加权警觉度达到阈值后启动，按各地区警觉 × 研究权重推进；`counter_resist` 减速。
6. **点数**：每转化 `convert_chunk` 人 +1，进入新地区 +N，随机“气泡”奖励（目前自动拾取）。
7. **结算**：`convert_all` / `remove_all` 获胜；反制完成或传播体消亡则失败。

升级的 `effects` 全部是加法属性，键名见 `spread_model.gd` 顶部注释。新增玩法属性时：在数据里加键 → 在 SpreadModel 里读取即可。

所有随机数来自 `SimWorld.rng`（固定种子可复现），存档包含 RNG 状态，读档后结果与不中断时完全一致（有测试覆盖）。

## 运行

```bash
godot --headless --path . --import
godot --headless --path . -s res://tests/run_tests.gd
```

编辑器中直接 F5 运行 `scenes/main.tscn`（默认加载真实世界场景 `data/scenarios/world.json`）。
操作：点击国家选中 → “在此国家开始”；左键拖动、滚轮缩放、WASD 平移；Tab 收起/展开右侧面板。

## 开发顺序建议

### 第 0 阶段：框架（本次完成）
- [x] 数据驱动的地区 / 连接 / 规则 / 升级
- [x] 每日模拟循环、跨区传播、警觉与封锁、反制、胜负
- [x] 点数经济与升级树（前置、花费、属性汇总）
- [x] 时钟与倍速、存读档、可复现随机数
- [x] 调试 UI、无界面测试、平衡报告

### 第 1 阶段：让一局“好玩”（最优先）
0. [x] 真实世界地图（灰色晕渲、中国视角、按国家划分、最高精度）
1. **定主题**——已定为原创题材；还需定文案、升级分支和胜负条件。
2. **平衡调参**：当前平衡报告显示“隐匿优先 20/20 胜，传播优先 0/20 胜”，反制过强且隐匿过强，需要调。可加入批量模拟脚本输出曲线。
3. **点数气泡交互**：点击才拾取，是这类游戏的核心手感。
4. **升级花费递增**（同分支每买一个，后续更贵）与**退化/退款**。
5. **随机事件系统**：数据驱动的事件（条件 + 效果 + 新闻文案），例如“某地区节庆，内部传播 +50% 持续 10 天”。

### 第 2 阶段：表现层
6. 地图动效：连接线上的飞机/船动画、点数气泡、封锁标记；手工校订主要航线和港口。
7. 地区详情面板、全球统计图（每日曲线）、新闻滚动条。
8. 主菜单、难度选择、结算界面。

### 第 3 阶段：深度
9. 反制方的主动行为（Religion 式“科学家/怀疑论者”单位、Plague 式“解药部署”降低转化）。
10. 多个“传播体类型”（不同起始属性与专属升级树）、多个场景地图。
11. 地区特征扩展（城市化、宗教/文化、交通枢纽）。
12. 本地化、音效、成就。

## 待讨论的决定

已定：原创题材、真实世界地图（中国视角，按国家划分）、PC 平台。

| 问题 | 影响 |
|---|---|
| 原创题材的具体设定 | 文案、升级分支、是否需要 `removed`（死亡） |
| 胜利条件：全转化还是全移除？ | `win_condition` |
| 反制只是进度条，还是有地图上的单位？ | 第 3 阶段工作量差异很大 |
